## 🌟 Featured Projects

### 1. 🛡️ Zerohub
- **Type:** Windows System Utility
- **Description:** Fast, safe, and intelligent cache cleaner for Windows Drive `C:`. Reclaims storage across 40+ cache targets (GPU shaders, web browsers, dev tools, gaming launchers, and social apps) without touching saved logins or active account sessions.
- **Repository:** [ZeroIQs/Zerohub](https://github.com/ZeroIQs/Zerohub)

## 🎨 UI & Tech Highlights

- **Aesthetics:** Neo-Brutalist & Comicmorphism design with bold ink outlines, dynamic card panels, and organic vector wave backgrounds.
- **Theme Engine:** Instant Light & Dark mode with directional sweep transitions using the native **View Transitions API**.
- **Internationalization (i18n):** Full bilingual support (Arabic & English) with locked typography (**Alexandria** for Arabic, **Space Grotesk** for English).
- **Mobile First:** Fully responsive layout optimized for all viewports (phones, tablets, desktops).
